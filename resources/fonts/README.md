# Quotation PDF fonts

IPAexGothic is the Japanese document font; its license is in `IPA_Font_License_Agreement_v1.0.txt`.

Noto Emoji supplies monochrome emoji when the Japanese font has no glyph. The font is bundled locally so PDF generation does not make network requests. mPDF also supplies DejaVu Sans Condensed for mathematical symbols.

- Source: [Google Fonts Noto Emoji](https://github.com/google/fonts/tree/main/ofl/notoemoji)
- Original file: `NotoEmoji[wght].ttf`, downloaded on 2026-10-30 and stored unchanged as `NotoEmoji.ttf` (the default regular outlines are used).
